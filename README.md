# DiscordRe: Discord redesign project

This project showcases possible design changes that can be made to the Discord user interface based on personal preference and ease-of-use, and features fully functional text messaging, file uploading, video calls, and more. This was mostly a personal exercise in fullstack development with TypeScript and integration of third-party services and APIs.
